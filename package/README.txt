mTLS Bridge for Splunk MCP (TA-mtls-bridge)

Terminates mutual TLS from MCP clients, maps each client certificate to a local Splunk
account, and forwards the call to the Splunk MCP Server app with that account's encrypted
MCP token. Configure it under Apps > mTLS Bridge for Splunk MCP > Configuration.

Requires Splunk Enterprise 10.4 or later on a standalone search head running the Splunk MCP
Server app.
