# splunk-mcp-mtls-bridge

A Splunk app that terminates mTLS from MCP clients and forwards their calls to the Splunk MCP Server app with a mapped account's bearer token. See `docs/DESIGN.md`.

## Development

The daemon lives in `package/bin/mtls_bridge` and uses only the Python standard library (3.9 and 3.13, the versions Splunk 10.4 runs). splunkd starts it through the `mtls_bridge_daemon` modular input in `package/bin/mtls_bridge_daemon.py`. The setup pages are generated by UCC from `globalConfig.json`.

```sh
python3.9 -m venv .venv && .venv/bin/pip install -r requirements-dev.txt
.venv/bin/pytest
```

To build the installable app and run AppInspect, as CI does:

```sh
.venv/bin/pip install -r requirements-build.txt
PATH=.venv/bin:$PATH scripts/build_app.sh 0.1.0
```

Install `output/TA-mtls-bridge-0.1.0.tgz` through Apps > Manage Apps > Install app from file, restart Splunk, then fill in the app's Configuration page.

To release, push a tag such as `v0.2.0`. CI tests it, builds the app at version 0.2.0 and attaches `TA-mtls-bridge-0.2.0.tgz` to a GitHub release for the tag.

To run the bridge outside Splunk, write a JSON file holding the `Config` fields and run `python -m mtls_bridge bridge.json` from `package/bin`.
